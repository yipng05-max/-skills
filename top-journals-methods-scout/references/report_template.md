## 摘要（Executive Summary）

300-500 字。必须包含：
1. 方法分布的整体画面（定性/定量/计算的比例与学科差异）
2. 本期最值得关注的 3 个方法新动向
3. AI 方法的总量与关键形态
4. 给课程策划人员的 2-3 条直接建议

## 一、方法家族分布全景

### 1.1 跨学科方法热力图
用表格呈现 L1 标签 × 学科的频次矩阵。只列出频次 ≥ 3 的单元格，避免无效信息。

### 1.2 学科方法画像
每个学科一小段（150-200 字）：
- 本学科主导方法（前 3）
- 与其他学科相比的方法独特性
- 该学科是否出现方法转向迹象

## 二、新兴方法（Emerging Methods）

识别标准：
- 近 24 个月才出现在顶刊、或频次显著上升
- 在方法专刊（SMR, Q&Q, PM 等）被专文讨论
- 跨学科扩散（一个学科创新被另一个学科采用）

每个新兴方法一小节，结构固定：
- **方法名称**
- **代表论文**（1-3 篇，给 DOI）
- **方法内核**（50-100 字，说明它解决什么问题）
- **与既有方法的关系**（延续 / 修正 / 挑战）
- **适用边界**（别过度乐观）
- **教学转化建议**（见第五章格式）

## 三、AI 方法专章

按 `ai_method_taxonomy.md` 的两大类组织。

### 3.1 AI-as-tool（AI 作为研究工具）
5 个子类（LLM 辅助定性 / LLM 文本分析 / 监督或无监督 ML / 计算机视觉 / 仿真生成）各一小节。
每小节包含：
- 论文频次与学科分布
- 2-3 个典型论文的一句话描述（方法+数据+发现）
- 该子类的方法论争论点（比如 LLM 编码的 hallucination 问题）

### 3.2 AI-as-object（AI 作为研究对象）
5 个子类（算法审计 / 数字民族志 / Prompt 话语分析 / AI 劳动与基础设施 / AI 治理与政策）同样处理。

### 3.3 Hybrid 类与前沿张力
单独列出那些既用 AI 做工具又研究 AI 的论文——这些通常最能启发课程设计。

### 3.4 AI 方法的伦理与效度挑战
专门一节讨论：
- 研究者如何处理数据同意/隐私
- 如何回应"AI 是黑箱"的审稿人质疑
- 人类编码员与 AI 编码一致性的典型做法

## 四、方法论文专栏（Methods Journals Spotlight）

从方法期刊（SMR、Q&Q、PM、FM）中挑选本期最值得关注的方法论创新（不是应用）。每篇一段说明其推进了什么。这类论文最适合作为研究生方法课的阅读材料。

## 五、教学转化建议（课程策划视角）

这是面向课程策划的核心章节，务必具体。

### 5.1 可立即上线的新模块（3-5 个）

每个模块格式：
```
模块名称：例：「LLM 辅助主题分析」
教学目标：学生做完这个模块能做什么
前置知识：需要什么基础（计算 / 统计 / 质性基础）
核心论文：2-3 篇可作读物
操作任务：课程作业原型（一句话）
课时建议：若干学时
风险提示：可能踩的坑
```

### 5.2 已有课程需要更新的点
哪些现有课程（如"社会研究方法""计算社会科学导论"）应根据本期扫描添加/删除哪些内容。

### 5.3 跨院系共建建议
哪些方法需要跨学科/跨院系合作教授（如 AI 审计需要计算机系合作）。
